### 安装使用步骤 📔

- **Install：**

```text
npm install
cnpm install (需要自行配置淘宝镜像)
```
- **Run：**

```text
npm run dev
npm run serve
```

- **Build：**

```text
npm run build
```

- **Lint：**

```text
# eslint 检测代码
npm run lint:eslint

# prettier 格式化代码
npm run lint:prettier

# stylelint 格式化样式
npm run lint:stylelint
```
