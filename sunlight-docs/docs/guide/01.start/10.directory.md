sunlight-admin 项目结构

## GitHub 仓库地址

```
https://github.com/sunlight-ui/sunlight-admin
```

## 获取代码步骤

1. **克隆仓库**

```bash
git clone https://github.com/sunlight-ui/sunlight-admin.git
```

2. **进入项目目录**

```bash
cd sunlight-admin
```

3. **安装依赖**

```bash
npm install
```

## 运行启动项目步骤

1. **开发环境启动**

```bash
# 使用 dev 命令启动（推荐）
npm run dev

# 或使用 serve 命令启动
npm run serve
```

2. **生产环境构建**

```bash
npm run build
```

3. **预览生产环境构建结果**

```bash
npm run preview
```
