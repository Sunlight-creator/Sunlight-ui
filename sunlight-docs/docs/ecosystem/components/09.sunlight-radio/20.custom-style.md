## 自定义样式

SunlightRadio 支持丰富的自定义样式配置，您可以通过 `wrapperStyle` 对象来自定义单选框的边框颜色、聚焦样式和选中样式等。

### 自定义边框颜色

您可以自定义单选框的边框颜色和选中时的边框颜色。

### 自定义聚焦样式

您可以自定义单选框聚焦时的边框颜色和阴影效果。

## 文档说明

### 自定义样式示例

SunlightRadio 提供了强大的自定义样式能力，通过 `wrapperStyle` 对象可以灵活配置单选框的各种样式属性，实现完全自定义的视觉效果。

### wrapperStyle 配置表

| 属性名              | 说明           | 类型     | 默认值                     |
| ------------------- | -------------- | -------- | --------------------------- |
| borderColor         | 单选框边框颜色 | `string` | `'#c0c4cc'`                 |
| focusBorderColor    | 聚焦时边框颜色 | `string` | `'#409eff'`                 |
| focusBoxShadowColor | 聚焦时阴影颜色 | `string` | `'rgba(64, 158, 255, 0.1)'` |
