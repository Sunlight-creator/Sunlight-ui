## 自定义样式
SunlightSelect 支持丰富的自定义样式配置，您可以通过 `wrapperStyle` 对象来自定义选择器的边框、圆角、背景色和聚焦样式等。
### 自定义边框颜色
您可以自定义选择器的边框颜色和聚焦时的边框颜色。
::: demo
sunlight-select/border-color
:::

### 自定义圆角
您可以通过 `borderRadius` 属性自定义选择器的圆角大小。
::: demo
sunlight-select/border-radius
:::

### 自定义背景色

您可以自定义选择器的背景色，适合不同的主题需求。
::: demo
sunlight-select/background-color
:::

### 自定义聚焦样式
您可以自定义选择器聚焦时的边框颜色和阴影效果。
::: demo
sunlight-select/custom-style
:::

## 文档说明

### wrapperStyle 配置表
| 属性名           | 说明                               | 类型     | 默认值                                |
| ---------------- | ---------------------------------- | -------- | -------------------------------------- |
| borderColor      | 选择器边框颜色                    | `string` | `'#c0c4cc'`                            |
| borderRadius     | 选择器圆角大小，支持像素值和百分比 | `string` | `'4px'`                                |
| backgroundColor  | 选择器背景色                       | `string` | `'inherit'`                            |
| boxShadow        | 选择器阴影效果                    | `string` | `'inherit'`                            |
| focusBorderColor | 聚焦时边框颜色                    | `string` | `'#409eff'`                            |
| focusBoxShadow   | 聚焦时阴影效果                    | `string` | `'0 0 0 3px rgba(64, 158, 255, 0.15)'` |
