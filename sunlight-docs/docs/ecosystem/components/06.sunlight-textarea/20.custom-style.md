## 自定义样式

SunlightTextarea 支持丰富的自定义样式配置，您可以通过 `wrapperStyle` 对象来自定义文本框的边框、圆角、背景色和聚焦样式等。

### 自定义边框颜色

您可以自定义文本框的边框颜色和聚焦时的边框颜色。

::: demo
sunlight-textarea/custom-style
:::

### 自定义圆角

您可以通过 `borderRadius` 属性自定义文本框的圆角大小。

::: demo
sunlight-textarea/rounded  
:::

### 自定义背景色

您可以自定义文本框的背景色，适应不同的主题需求。

::: demo
sunlight-textarea/background-color
:::

### 自定义聚焦样式

您可以自定义文本框的聚焦时的边框颜色和阴影效果。

::: demo
sunlight-textarea/focus-style  
:::

## 文档说明

### 自定义样式示例

SunlightTextarea 提供了强大的自定义样式能力，通过 `wrapperStyle` 对象可以灵活配置文本框的各种样式属性，实现完全自定义的视觉效果。

### wrapperStyle 配置表

| 属性名           | 说明                               | 类型     | 默认值                                |
| ---------------- | ---------------------------------- | -------- | -------------------------------------- |
| borderColor      | 文本框边框颜色                    | `string` | `'#c0c4cc'`                            |
| borderRadius     | 文本框圆角大小，支持像素值和百分比 | `string` | `'4px'`                                |
| backgroundColor  | 文本框背景色                       | `string` | `'inherit'`                            |
| boxShadow        | 文本框阴影效果                    | `string` | `'inherit'`                            |
| focusBorderColor | 聚焦时边框颜色                    | `string` | `'#409eff'`                            |
| focusBoxShadow   | 聚焦时阴影效果                    | `string` | `'0 0 0 3px rgba(64, 158, 255, 0.15)'` |
